    修改口令

    需先验证当前口令；保存后所有已登录会话立即失效，请用新口令重新登录。 口令仅存 scrypt 哈希（server/.pw-hash），明文不落盘；若服务以 ADMIN_PW 环境变量启动，重启后以环境变量为准。

    修改访问口令

    改的是访问口令（防误触的那道门），不是 GitHub 令牌——令牌要去 GitHub → Settings → Developer settings → Fine-grained tokens 改或删。
    保存方式：浏览器重新计算 PBKDF2 哈希，只把 admin.html 里那行哈希常量替换掉（写入即 commit）。口令明文永不写入任何文件，commit 记录里也只有哈希。
    生效：Pages 重建约 1 分钟；本页要刷新后才用新口令（本页此刻已切到新哈希）。若提交失败，旧口令继续有效，可放心重试。
